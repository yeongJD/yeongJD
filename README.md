## AI-assisted, verification-led

I use AI to accelerate exploration, implementation drafts, and review—not to skip engineering judgment. Every meaningful change follows a deliberate loop:

`inspect the source of truth` → `isolate a reviewable change` → `test, type-check, and build` → `review PR checks` → `verify the real user path`

For AI and automation products, I focus on the same foundations: explicit permissions, safe failure paths, reproducible artifacts, and observable results.
