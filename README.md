## AI-assisted, verification-led

I use AI to accelerate repository exploration, implementation drafts, and review—not to replace engineering judgment. I remain responsible for the contracts, the diff, and the outcome.

`inspect the source of truth` → `isolate a reviewable change` → `test, type-check, and build` → `review PR checks` → `verify the real user path`

The same principle guides my AI and automation work: make permissions explicit, contain failure safely, preserve reproducible artifacts, and leave observable evidence.
